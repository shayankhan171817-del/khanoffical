# Shayan Khan Portfolio

## Files
- `index.html` — page content and sections
- `style.css` — colors, responsive layout, and visual styling
- `script.js` — mobile navigation, project detail dialogs, reveal effects, form validation
- `README.md` — these instructions

## Run locally
1. Extract the ZIP.
2. Open the `shayan-portfolio` folder.
3. Double-click `index.html` to open it in a modern browser.
4. Optional: open the folder in Visual Studio Code and use the Live Server extension.

No installation or build process is required. Google Fonts uses an internet connection; system fallback fonts are included.

## Customize
- Edit name, bio, location, education, courses, and project text in `index.html`.
- Change the CSS variables at the top of `style.css` to adjust the theme.
- Replace the letter “S” in the hero avatar with your own image and add suitable image sizing in CSS.
- Update skill bar widths and labels to honestly reflect your learning. Current widths are illustrative placeholders, not measured scores.
- Project cards are examples, not claimed completed projects. Replace them with real projects, screenshots, technologies, and working URLs when available.
- Replace `YOUR_EMAIL@example.com` in both the visible email and `mailto:` link before publishing.

## Contact form
The form validates entries in the browser only. It does not send or save messages. Connect a trusted form service or a backend before using it to receive submissions. Never put private API keys in front-end code.
